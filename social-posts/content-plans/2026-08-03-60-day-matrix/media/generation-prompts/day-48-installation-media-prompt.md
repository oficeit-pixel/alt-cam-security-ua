# День 48 — media prompt

Тема: До/після: акуратне кабелювання і серверний щит для приватний будинок: антифакап для дому й бізнесу
Контур: Offer
Об’єкт: приватний будинок

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: entrance — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: жовта підсвітка проблемної зони. Крупний план проблеми для об’єкта “приватний будинок”: Після швидкого монтажу залишаються висячі кабелі, хаос у щиті та незрозуміло, що за що відповідає. Текст: “Не робіть так: Монтаж, який не соромно показати.”.
- 3–8s — як може бути / як у сусіда: Саме з таких дрібниць починаються великі переробки. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для приватний будинок: Маркуємо лінії, збираємо охайний щит, перевіряємо доступ, архів, резерв і навчаємо клієнта. Адаптуємо під об’єкт: приватний будинок. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: Кабель UTP/FTP, PoE-комутатор, NVR, UPS, маркування, фотофіксація після монтажу. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «МОНТАЖ» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
