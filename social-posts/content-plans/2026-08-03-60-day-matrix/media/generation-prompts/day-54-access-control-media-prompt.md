# День 54 — media prompt

Тема: СКУД для офісу: як прибрати хаос із ключами для виробництво: чек-лист перед покупкою
Контур: Expert
Об’єкт: виробництво

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: installer — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: контраст “у сусіда / у нас”. Крупний план проблеми для об’єкта “виробництво”: Ключі передаються між співробітниками, а після звільнення доступ може залишитися. Текст: “Перевірте: Хто досі має ключ від вашого офісу?”.
- 3–8s — як може бути / як у сусіда: Більшість пропускає цей пункт, а потім дивується результату. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для виробництво: Встановлюємо електрозамок, контролер, зчитувач і керуємо доступами картками або через систему. Адаптуємо під об’єкт: виробництво. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: Контролер, зчитувач, електрозамок, кнопка виходу, БЖ, журнал подій. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «СКУД» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
