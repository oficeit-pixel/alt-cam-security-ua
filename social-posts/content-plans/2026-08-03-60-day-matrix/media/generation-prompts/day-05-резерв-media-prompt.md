# День 05 — media prompt

Тема: Блекаут: що вимкнеться першим — камери, роутер чи Ajax для магазин: скільки коштує помилка
Контур: Captivate
Об’єкт: магазин

Стиль: реалістичний security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, монтажник у брендованій формі.

Кадри для генерації/анімації:
- 0–3s — гачок: до/після одним монтажним переходом. Крупний план проблеми для об’єкта “магазин”: Камери можуть мати живлення, але роутер або ONU вимикаються — і віддаленого доступу немає. Текст: “Ціна помилки: Світло зникло. Безпека теж?”.
- 3–8s — як може бути / як у сусіда: Найдорожче — переробляти тоді, коли проблема вже сталася. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для магазин: Резервуємо весь ланцюг: камери, NVR, PoE, роутер, ONU, Ajax і критичні датчики. Адаптуємо під об’єкт: магазин. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: UPS або LiFePO4, розрахунок у Wh, захист АКБ, окрема лінія для мережевого обладнання. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «РЕЗЕРВ» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
