# День 57 — media prompt

Тема: Ложні тривоги Ajax: чому систему вимикають для салон: міф, який коштує грошей
Контур: Captivate
Об’єкт: салон

Стиль: реалістичний security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, монтажник у брендованій формі.

Кадри для генерації/анімації:
- 0–3s — гачок: різкий zoom-in на проблему. Крупний план проблеми для об’єкта “салон”: Через хибні спрацювання власник перестає довіряти системі та вимикає охорону. Текст: “Міф: Найгірша сигналізація — та, яку вимкнули.”.
- 3–8s — як може бути / як у сусіда: Сусід теж думав, що цього достатньо — поки система не знадобилась. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для салон: Перевіряємо висоту датчиків, тварин, штори, протяги, сценарії, затримки та якість зв’язку. Адаптуємо під об’єкт: салон. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: Ajax Hub, MotionProtect, DoorProtect, сирени, сценарії, користувачі, резерв. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «ТРИВОГА» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
