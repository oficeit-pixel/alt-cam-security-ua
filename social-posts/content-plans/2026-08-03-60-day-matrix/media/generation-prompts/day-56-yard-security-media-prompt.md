# День 56 — media prompt

Тема: Двір приватного будинку: як закрити сліпі зони для ОСББ: антифакап для дому й бізнесу
Контур: Offer
Об’єкт: ОСББ

Стиль: реалістичний security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, монтажник у брендованій формі.

Кадри для генерації/анімації:
- 0–3s — гачок: жовта підсвітка проблемної зони. Крупний план проблеми для об’єкта “ОСББ”: Одна камера дивиться на ворота, але калитка, гараж або бокова зона залишаються без контролю. Текст: “Не робіть так: А тут ваша камера бачить?”.
- 3–8s — як може бути / як у сусіда: Саме з таких дрібниць починаються великі переробки. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для ОСББ: Будуємо схему покриття за маршрутами руху: ворота, калитка, вхід, гараж, паркомісце. Адаптуємо під об’єкт: ОСББ. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: 4–8 IP-камер, нічний режим, PoE, архів 14–30 днів, UPS. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «ДВІР» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
