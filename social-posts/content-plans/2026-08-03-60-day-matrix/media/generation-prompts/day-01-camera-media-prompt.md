# День 01 — media prompt

Тема: 5 помилок монтажу камер, через які не видно обличчя для квартира: міф, який коштує грошей
Контур: Captivate
Об’єкт: квартира

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: problem — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: різкий zoom-in на проблему. Крупний план проблеми для об’єкта “квартира”: Камери встановлені, але обличчя, номер авто або момент події не читаються. Текст: “Міф: Камера є. Доказів — нуль.”.
- 3–8s — як може бути / як у сусіда: Сусід теж думав, що цього достатньо — поки система не знадобилась. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для квартира: Починаємо зі схеми огляду, висоти, нічної сцени, архіву та резерву, а не з випадкової покупки камери. Адаптуємо під об’єкт: квартира. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: IP-камери 4 Мп, AcuSense/SMD, PoE, NVR, HDD від 2 ТБ, UPS для мережі. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «КАМЕРА» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
