# День 37 — media prompt

Тема: Ajax + камери: як зрозуміти, що сталося під час тривоги для салон: скільки коштує помилка
Контур: Captivate
Об’єкт: салон

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: object — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: до/після одним монтажним переходом. Крупний план проблеми для об’єкта “салон”: Окремі системи дають багато сповіщень, але користувач не розуміє, це загроза чи хибна тривога. Текст: “Ціна помилки: Тривога є. А що саме сталося?”.
- 3–8s — як може бути / як у сусіда: Найдорожче — переробляти тоді, коли проблема вже сталася. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для салон: Поєднуємо сценарій Ajax, візуальну перевірку камерами, сирену, резерв і зрозумілу реакцію. Адаптуємо під об’єкт: салон. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: Ajax Hub, MotionProtect/DoorProtect, сирена, IP-камери, NVR, UPS. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «AJAX» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
