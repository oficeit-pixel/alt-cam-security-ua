# День 29 — media prompt

Тема: Самостійний монтаж: чому переробка часто дорожча для склад: скільки коштує помилка
Контур: Captivate
Об’єкт: склад

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: object — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: до/після одним монтажним переходом. Крупний план проблеми для об’єкта “склад”: Кабелі висять, камера дивиться занадто високо, архів не пишеться, застосунок втрачає зв’язок. Текст: “Ціна помилки: Дешево спочатку — дорого після переробки.”.
- 3–8s — як може бути / як у сусіда: Найдорожче — переробляти тоді, коли проблема вже сталася. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для склад: Переробляємо схему, кабель, кути камер, архів, доступ і резерв так, щоб система працювала цілісно. Адаптуємо під об’єкт: склад. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: Аудит, кабель-канал, перенесення камер, NVR/HDD, PoE, налаштування смартфона. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «АУДИТ» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
