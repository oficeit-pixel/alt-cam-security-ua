# День 16 — media prompt

Тема: 5 помилок монтажу камер, через які не видно обличчя для ОСББ: антифакап для дому й бізнесу
Контур: Offer
Об’єкт: ОСББ

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: sergey — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: жовта підсвітка проблемної зони. Крупний план проблеми для об’єкта “ОСББ”: Камери встановлені, але обличчя, номер авто або момент події не читаються. Текст: “Не робіть так: Камера є. Доказів — нуль.”.
- 3–8s — як може бути / як у сусіда: Саме з таких дрібниць починаються великі переробки. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для ОСББ: Починаємо зі схеми огляду, висоти, нічної сцени, архіву та резерву, а не з випадкової покупки камери. Адаптуємо під об’єкт: ОСББ. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: IP-камери 4 Мп, AcuSense/SMD, PoE, NVR, HDD від 2 ТБ, UPS для мережі. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «КАМЕРА» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
