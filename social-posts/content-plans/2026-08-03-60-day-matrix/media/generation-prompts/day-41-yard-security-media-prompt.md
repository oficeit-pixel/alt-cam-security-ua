# День 41 — media prompt

Тема: Двір приватного будинку: як закрити сліпі зони для квартира: міф, який коштує грошей
Контур: Captivate
Об’єкт: квартира

Стиль: живий кричащий security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, крупний продукт або людина в кадрі, монтажник у брендованій формі.
Варіант заставки: problem — товар / Аліса / Сергій / проблема чергуються, щоб медіа не повторювалися.

Кадри для генерації/анімації:
- 0–3s — гачок: різкий zoom-in на проблему. Крупний план проблеми для об’єкта “квартира”: Одна камера дивиться на ворота, але калитка, гараж або бокова зона залишаються без контролю. Текст: “Міф: А тут ваша камера бачить?”.
- 3–8s — як може бути / як у сусіда: Сусід теж думав, що цього достатньо — поки система не знадобилась. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для квартира: Будуємо схему покриття за маршрутами руху: ворота, калитка, вхід, гараж, паркомісце. Адаптуємо під об’єкт: квартира. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: 4–8 IP-камер, нічний режим, PoE, архів 14–30 днів, UPS. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «ДВІР» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
