# День 50 — media prompt

Тема: Блекаут: що вимкнеться першим — камери, роутер чи Ajax для кав’ярня: помилка, яку видно лише після проблеми
Контур: Expert
Об’єкт: кав’ярня

Стиль: реалістичний security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, монтажник у брендованій формі.

Кадри для генерації/анімації:
- 0–3s — гачок: пауза перед вердиктом. Крупний план проблеми для об’єкта “кав’ярня”: Камери можуть мати живлення, але роутер або ONU вимикаються — і віддаленого доступу немає. Текст: “Помилка: Світло зникло. Безпека теж?”.
- 3–8s — як може бути / як у сусіда: У сусіда все виглядало нормально, але запис не допоміг. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для кав’ярня: Резервуємо весь ланцюг: камери, NVR, PoE, роутер, ONU, Ajax і критичні датчики. Адаптуємо під об’єкт: кав’ярня. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: UPS або LiFePO4, розрахунок у Wh, захист АКБ, окрема лінія для мережевого обладнання. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «РЕЗЕРВ» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
