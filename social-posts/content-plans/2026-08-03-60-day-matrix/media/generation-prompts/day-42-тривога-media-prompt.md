# День 42 — media prompt

Тема: Ложні тривоги Ajax: чому систему вимикають для офіс: помилка, яку видно лише після проблеми
Контур: Expert
Об’єкт: офіс

Стиль: реалістичний security-tech ALT-CAM, антрацит/графіт, жовтий #FFCC00, монтажник у брендованій формі.

Кадри для генерації/анімації:
- 0–3s — гачок: пауза перед вердиктом. Крупний план проблеми для об’єкта “офіс”: Через хибні спрацювання власник перестає довіряти системі та вимикає охорону. Текст: “Помилка: Найгірша сигналізація — та, яку вимкнули.”.
- 3–8s — як може бути / як у сусіда: У сусіда все виглядало нормально, але запис не допоміг. Текст: “У сусіда було так само”.
- 8–15s — рішення: Монтажник ALT-CAM у брендованій формі показує рішення для офіс: Перевіряємо висоту датчиків, тварин, штори, протяги, сценарії, затримки та якість зв’язку. Адаптуємо під об’єкт: офіс. Текст: “Рішення ALT-CAM”.
- 15–23s — доказ / специфікація: Показати обладнання, застосунок, акуратний монтаж або схему: Ajax Hub, MotionProtect, DoorProtect, сирени, сценарії, користувачі, резерв. Текст: “Перевірено на об’єкті”.
- 23–30s — CTA: Фінальний кадр із логотипом ALT-CAM, Telegram-ботом і географією роботи. Текст: “Напишіть «ТРИВОГА» у бот”.

Уникати: кров, зброя, поліція/військовий стиль, випадкові бренди, дрібний нечитабельний текст.
