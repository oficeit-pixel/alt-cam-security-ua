# C-P2-03: товарные страницы

- Весь каталог сохраняется. Для поисковой карты выбираются максимум 300 карточек пяти целевых категорий с положительной ценой и описанием от 300 символов без заглушек.
- Стабильная сортировка ID и поочередный выбор категорий не зависят от порядка фида. На текущем каталоге из 9296 товаров выбраны 300: по 60 камер, регистраторов/накопителей, домофонов, Ajax и резервного питания. Это технический отбор качества данных, не утверждение о популярности товаров.
- Остальные страницы доступны покупателям, но получают `noindex,follow`. Итоговый `product-seo-report.json` содержит количество и выбранные публичные пути; sitemap проверяется против отчета.
- Product/Offer формируются только при положительной конечной числовой цене. Цена в UAH совпадает с видимой ценой карточки. Данные берутся из каталога при сборке; проверка наличия у поставщика в реальном времени не добавлена.
- Только явный `available: true` означает InStock на статической странице. Иначе PreOrder. Отзывы, рейтинги, скидки и сроки действия цены не выдумываются.
- На страницах камер и домофонов добавлены работы из единого `data/service-rates.js`, отдельно от стоимости оборудования, и ссылки на услуги.
- Каталог больше не выдает Product для товара без цены и не считает неизвестное наличие подтвержденным.

Проверки: лимит и стабильность отбора, отсев коротких описаний/невалидных цен, наличие Offer, соответствие видимой цены JSON-LD, тарифы из общего источника, sitemap и noindex. Требования сверены с https://developers.google.com/search/docs/appearance/structured-data/product-snippet . Это не гарантирует расширенный результат в Google; требуется переобход. Внешний Rich Results Test и фактическая индексация не подтверждены этими локальными тестами.
