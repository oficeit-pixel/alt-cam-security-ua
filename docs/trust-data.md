# Данные доверия

Единственный новый источник: data/trust.json. Заполните только подтверждённые сведения.
Пустые строки, TODO_OWNER и невалидные поля не выводятся. Файл данных не копируется в публичную сборку.

- reviews: массив объектов name, locality (объект/населённый пункт), text,
  date (YYYY-MM-DD), source (HTTPS-ссылка на конкретный отзыв Google Maps/Facebook),
  verified: true после проверки владельцем. rating — необязательное реальное число 1–5,
  его нельзя выводить из текста отзыва. Дубликаты source не учитываются.
- legal: name (ФОП/юридическое лицо), code (ЄДРПОУ/РНОКПП), address (юридический адрес).
  Полная строка появляется только при заполнении всех трёх полей. Это не адрес приёма клиентов.
- openingHours: массив строк Schema.org, например Mo-Fr 09:00-18:00.
  Пример формата, НЕ утверждённый график ALT-CAM. Часовой пояс — местный для бизнеса.
- installationWarrantyMonths: подтверждённое положительное целое число месяцев.
- team: подтверждённое описание монтажной команды, без вымышленных стажа и сертификатов.
- sameAs: HTTPS-ссылки на официальные профили именно ALT-CAM.
- dealerships: по умолчанию []; элементы brand, confirmed: true, source (подтверждение),
  logo (существующий локальный путь /assets/…). Подтверждение и права на логотип проверяет владелец.
  Без подтверждения на главной остаются текстовые названия производителей.

После изменения данных нужна сборка сайта. Не меняйте data/reviews.json:
старый renderer сохранён для совместимости тестов, но главная его больше не использует.
Не дублируйте новые реквизиты/гарантии в legacy-полях contacts.js.

## Разметка отзывов

HomeAndConstructionBusiness — подтип LocalBusiness. openingHours и sameAs берутся
из trust.json. Review/AggregateRating по умолчанию выключены (reviewSchemaEnabled: false).
Даже реальные отзывы о собственной компании не дают права на звёзды Google:
https://developers.google.com/search/docs/appearance/structured-data/review-snippet
Google также не рекомендует агрегировать скопированные оценки сторонних сайтов.
Поэтому для данного сайта рекомендуем оставить флаг выключенным.
Если разметка включается для другого потребителя Schema.org, она появляется только
на главной с видимыми, подтверждёнными отзывами и ссылками. Среднее формируется
лишь когда у каждого опубликованного отзыва есть реальная числовая оценка.

sameAs перенесены из существующего contacts.js без изменения адресов.
