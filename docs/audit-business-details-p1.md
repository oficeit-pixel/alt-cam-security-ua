# C-P1-08: технический вывод подтверждённых сведений

Сборка читает legalName/legalCode/legalAddress, warrantyWorks/warrantyEquipment
и yearsExperience из contacts.js. Реквизиты и гарантии добавляются в футеры
публичных страниц, включая сгенерированные лендинги и карточки товаров.
Для страниц без футера создаётся футер. Админка, печатные бланки и OAuth callback
исключены: реквизиты для выставления счета нельзя подменять автоматически.

Неподтверждённая карточка «10+» удалена; опыт появляется только при заданном
положительном целом yearsExperience. Пустые сведения не выводятся. Значения
экранируются, повторная финализация не дублирует блок. Юридические сведения,
сроки гарантий и стаж не заполнены вымышленными значениями.

Остаётся владельцу подтвердить актуальные реквизиты, сроки гарантий и стаж.
Подключение этих сведений к печатным бланкам требует отдельной проверки.
