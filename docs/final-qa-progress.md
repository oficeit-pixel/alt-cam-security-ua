# Финальная проверка: промежуточный отчёт

Проверяется локальная сборка `_site`, а не опубликованный сайт. Изменения не выложены.

## Подтверждено

- 19 unit-тестов: расчёты, нормализация телефона, транспорт заявок, статьи и контакты.
- Проверка украинских текстов, SEO head и ещё 5 тестов sitemap/Product/Offer прошли.
- Браузер: 390×844 и 1440×900. Три калькулятора (видео, питание, Ajax), форма консультации и корзина отправляют JSON на `/api/lead`.
- Три разных товара добавляются в корзину; после перезагрузки страницы корзина сохраняется.
- Полный квиз прошёл на обоих размерах экрана, заявка имеет source_form=quiz.
- Виджет повторно проверен на 390/768/1366: согласие yes/no, успешная отправка и fallback, фокус и Escape. JS: 3507 байт gzip.
- В проверенных сценариях нет исключений JavaScript и отсутствующих локальных ресурсов.
- API перехвачен тестом: реальная доставка в Telegram не проверена и не выполнялась. Внешние ресурсы также замещены; их доступность этими тестами не подтверждается.
- SEO-инвентаризация: 9063 страницы и столько же URL sitemap, без выявленных битых внутренних ссылок и ошибок canonical/XML/JSON-LD.

## Осталось

- Lighthouse mobile для трёх типов страниц: инструмент ещё не установлен, метрики не получены.
- Полная браузерная проверка переходов меню и подвала.
- Отдельная проверка внешних ресурсов и опубликованной версии.
- Дубли товаров: 89 групп title, 71 группа H1, 153 группы description; не исправлять выдумыванием моделей. 14 пустых alt требуют отличать декоративные изображения от содержательных.
