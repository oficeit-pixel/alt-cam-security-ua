сценарии для подъезда, магазина и жилья; таблиц цен больше нет. Удалена также
разметка AggregateOffer без видимого прайса, сохранена Service.
Ценовая страница: тарифы, сравнение одинакового объёма работ, раздельный расчёт
внутренних и уличных камер, условия трасс и выезда. Добавлены по четыре
уникальных абзаца и по одному FAQ, понятные взаимные ссылки.
URL и self-canonical сохранены, noindex не добавлен.

Проверено: чистая сборка, тест шести лендингов (метаданные, видимый контент,
FAQ/JSON-LD, ссылки, sitemap), тест разных интентов; украинский линтер.
Браузерная проверка не выполнена: локальный Playwright отсутствует.

Полный отчёт после node scripts/audit-intents-kits.mjs:
- outputs/intents-kits-audit/all-pages.md — URL → title → H1 для 9059 HTML.
- outputs/intents-kits-audit/duplicates.json — 90 групп совпадающих title
  и 72 группы H1, включая служебные страницы и карточки товаров.

Важно: отсутствие дублей по всему сайту НЕ подтверждено. Две страницы
Вишгорода различаются, но оставшиеся товарные/служебные дубли требуют
отдельной обработки; автоматически выдумывать модели товаров нельзя.
Проверка относится к локальной сборке, не к индексу Google.
