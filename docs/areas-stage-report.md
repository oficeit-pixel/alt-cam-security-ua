# Зоны и тариф выезда — первый этап

Реализовано локально, не опубликовано.

- `data/areas.json`: утверждённые владельцем зоны и тариф. Расстояния неизвестных населённых пунктов — null. Кейсы и FAQ не выдуманы.
- `data/travel-fee.mjs`: общий расчёт для сборки и браузера; неизвестное расстояние не равно нулю. Проверка допуска населённых пунктов к публикации требует описанного кейса с фото, времени выезда и трёх двуязычных FAQ. Реальную достоверность кейсов должен проверять редактор.
- `scripts/build-travel-pages.mjs`: украинская и русская страницы стоимости, таблица, примеры, интерактивный выбор пункта. Локальный словарь uk/ru — основа нового раздела, не утверждение о наличии полноценного i18n всего сайта.
- `scripts/build-site.mjs`: генератор подключён до финализации SEO.
- `AGENTS.md`: языковое правило согласовано с новым запросом владельца.

Проверено: четыре unit-теста; отдельная генерация двух страниц; браузер 390×844 — смена населённого пункта, неизвестное расстояние, бесплатный выезд, отсутствие горизонтального переполнения и ошибок JavaScript.

Не проверено: полный цикл сборки после этого изменения, интеграция новых URL в итоговый sitemap, окончательный вид после глобальных обработчиков. Общие footer/widget пока украинские; перед публикацией русской версии необходимо локализовать и их. Деплой не выполнен.

Дальше: общий языковой механизм для навигации/виджета, хабы зон, уникальные страницы Киева/Вышгорода без конкурирующих дублей, карта настоящих HTTP 301 перед миграцией существующих URL. Старые URL и корзина не изменены. Требуется окончание ТЗ, оборванного в пункте 2.4; отсутствующее время выезда нельзя получать выдуманным расчётом.
