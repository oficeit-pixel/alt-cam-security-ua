# C-P1-07 — границы расчётов

- Числовые поля трёх калькуляторов ограничиваются их min/max перед FormData.
- Чистые clampNumber/powerRuntime вынесены в data/calc-core.js.
- Модель видео дополнительно ограничивает количества до 64/64/16,
  приводит дробные количества к целым, проверяет допустимые NVR/HDD.
- Ноль камер: нет стоимости/завдатка, очищен предыдущий расчёт; кнопки заявки
  и КП отключены, обработчики защищены, показано «Додайте хоча б одну камеру».
- Ноль ватт приводится к 10 Вт; автономность не рассчитывается делением на ноль.
- Недостижимые старые модели после return удалены во всех трёх калькуляторах.
- Unit-тесты: отрицательные/пустые/нечисловые/999, нулевой комплект, мощность,
  атрибуты полей. Браузерные тесты проверяют ноль/999, кнопки, 10 Вт и Ajax 100.

Ставки и формула цен не изменялись. Превышение каналов выбранного NVR по-прежнему
показывается предупреждением; это не проверка электрической совместимости проекта.
