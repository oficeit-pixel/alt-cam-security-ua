# Цены комплектов и корзина

Единственный источник цен шести комплектов: data/kits.json. Владелец заполняет
price_from_uah (оборудование) и price_from_with_install_uah (с монтажом) числами
в гривнах. TODO_OWNER или отсутствующее значение отображается «за розрахунком».
JSON с плейсхолдерами не копируется в публичную сборку. После изменения — сборка сайта.

Автооценка: ALTCAM_PRICING.calculateVideo с конфигурациями data/package-configs.js.
Она использует приблизительные цены оборудования и политику скидки калькулятора.
Поэтому это сравнение для владельца, а не автоматически опубликованная цена.
Команда node scripts/audit-intents-kits.mjs после сборки создаёт сравнение
outputs/intents-kits-audit/kit-comparison.json: цена владельца, оценка, разница.
Для домофона, Ajax и UPS базовый состав по моделям ещё не утверждён: TODO_OWNER.

Корзина: оборудование считается отдельно от выбранного монтажа камер.
Число внутренних и уличных камер вводится явно — категория товара сама по себе
не подтверждает условия монтажа. Тарифы — data/service-rates.js, без скидок
калькулятора, без кабеля/материалов/высотных работ. Контрольные суммы:
2 внутренних = 2×800+800+150 = 2550;
2 внутренних + 2 уличных = 1600+1800+950 = 4350;
4 внутренних + 4 уличных = 2400+2800+950 = 6150.
Другие услуги и товары без цены остаются «за розрахунком», а не бесплатными.
Расчёт монтажа передаётся в комментарии заявки; окончательный счёт подтверждает менеджер.

localStorage сохраняет корзину между страницами. При запрете хранилища
сохраняется работа в текущей вкладке и выводится предупреждение; гарантировать
сохранность после закрытия страницы в этом режиме невозможно.
