# Индексация всего ассортимента — 05.10.2026

По новому поручению владельца отменены лимит 300, ограничение пятью категориями и порог длины описания. Все генерируемые публичные карточки с ID и названием разрешены для индексации и включаются в sitemap-products.xml. Служебные страницы и редиректы сохраняют исключения. Карточки без подтвержденной цены остаются с «Ціна за запитом», без фиктивного Offer.

Это разрешение индексации, не подтверждение присутствия в Google. Поле indexed старого отчета сборки сохранено для совместимости, добавлено indexable и пояснение. Ранний этап ограничения в 300 URL из ТЗ заменен этим решением владельца. Короткие или однотипные карточки Google по-прежнему может не включить в поиск.

Предоставленная 05.10 таблица Coverage содержит агрегаты только за 21.09, без конкретных URL. Для проверки Google-selected canonical и статуса отдельных карточек нужен актуальный отчет URL Inspection/экспорт примеров в Search Console. Автоматическая массовая отправка через Indexing API для товарных страниц не применяется.
