# C-P2-02: централизованная индексация

Карты страниц и товаров формирует только `scripts/finalize-seo.mjs` по готовым HTML-файлам. Генераторы категорий, локальных страниц и товаров больше не дописывают XML. Главная карта содержит ссылки на две дочерние карты.

Админка, бланки и OAuth callback получают `noindex,nofollow`; редиректы и любые страницы с noindex исключаются из карт. Robots исключает служебные пути и указывает основной домен. Canonical нормализуется для всех обычных HTML-страниц, включая юридические страницы и доставку. Ссылки `index.html#…` приводятся к `/#…`.

Lastmod берётся из истории соответствующего исходника: обычный HTML, генератор группы/локальной страницы или каталог для товаров. При отсутствии истории используется дата сборки. Pages загружает полную историю Git. Это дата изменения исходника, а не искусственная ежедневная дата обновления товара.

Проверка сборки: каждый URL карты существует, имеет title, description, свой canonical и корректную дату; служебные URL не включены. Отдельно проверяется noindex админки, бланков и callback.

Отбор ценных товаров и Product/Offer относятся к следующему пункту C-P2-03: этот коммит не меняет ассортимент или цены и пока сохраняет существующий набор товарных URL.
