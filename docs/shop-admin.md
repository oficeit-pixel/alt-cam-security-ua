# ALT-CAM Shop Admin

## Вхід

Публічної реєстрації адміністраторів немає. Вхід: `/admin.html`.

Обов'язкові змінні Render:

- `ADMIN_WEB_EMAIL=altcam777@gmail.com`
- `ADMIN_WEB_PASSWORD` — унікальний довгий пароль
- `ADMIN_SESSION_SECRET` — випадковий секрет не менше 32 байтів
- `NOVA_POSHTA_API_KEY` — серверний ключ API Нової пошти
- `AUTO_CREATE_DB=true`

Пароль і ключі не додаються до GitHub. Адмін-сесія діє 8 годин і зберігається
тільки в `sessionStorage` поточної вкладки.

## Можливості

- дашборд замовлень, подій і популярних товарів;
- список замовлень, статуси та коментар менеджера;
- індивідуальні роздрібні ціни поверх XML-фіда;
- аналітика переглядів, запитів ціни, кошика та оформлення;
- доставка Новою поштою: відділення, поштомат, кур'єр;
- самовивіз: Вишгород, Кургузова 1А.

## Розгортання

Для наявної бази виконайте `alembic upgrade head`. Якщо `AUTO_CREATE_DB=true`,
відсутні таблиці також створюються під час запуску сервісу.
