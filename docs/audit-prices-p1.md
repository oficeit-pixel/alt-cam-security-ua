# C-P1-03 — единый источник ставок, промежуточный этап

Ставки PDF_RATES перенесены без изменения в data/service-rates.js.
Калькулятор и варианты работ в каталоге читают этот файл. Старый draft не
подключается и не публикуется. Комплексные услуги и комплекты без точного
состава теперь имеют цену по расчёту, а не несогласованные фиксированные суммы.
Цены товаров поставщиков не менялись. Существующая скидочная политика калькулятора
не изменена; варианты работ в каталоге обозначают базовые ставки.

В ТЗ противоречие: шесть наружных камер ожидаются за 3600, но сохранённая ставка
для 3–8 камер равна 700, то есть 4200. Без решения владельца ставку не менять.
Пример 2 внутренних + 2 наружных + NVR + смартфон = 4350 подтверждается.

Обновление: общая модель видеокомплектов вынесена в data/price-calculator.js,
явные конфигурации 2/4/8 камер — data/package-configs.js. Карточки показывают
предварительную оценку той же функции, что калькулятор, с составом и пояснением
«оборудование + монтаж + базовые материалы». Нажатие переносит конфигурацию
в калькулятор, включая включённый монтаж и исходные настройки бренда/ночного режима.
Браузерный тест сравнивает отображённые суммы каждой карточки и калькулятора.
Числа оборудования и скидочная политика сохранены из прежнего калькулятора,
они не заявляются как проверенная цена конкретного товара поставщика.

Остаётся: Ajax/домофон/UPS — состав требует точного определения, поэтому только
расчёт по запросу; генераторы цен лендингов (C-P2-06). C-P1-03 полностью не закрыт.
