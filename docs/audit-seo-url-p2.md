# C-P2-01 — URL раздела видеонаблюдения

Основная страница генерируется по /videosposterezhennia/. Старый адрес
/videospheterezhennia/ сохранён как HTML-переход с meta refresh, canonical
на новый адрес, noindex,follow и видимой ссылкой. Sitemap содержит только новый
URL; ссылки, генерируемые на главной, используют новый URL.

Это HTML-переход на статическом хостинге, не серверный HTTP 301.
Тест создаёт изолированную сборку разделов, проверяет оба файла, canonical,
noindex, переход и отсутствие старого адреса в sitemap.
