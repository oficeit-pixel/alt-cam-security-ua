# Правила работы над ALT-CAM Security UA

Область действия: весь репозиторий сайта https://alt-cam.net.ua/.
Направление: монтаж видеонаблюдения и систем безопасности, Киев и Вишгород.

1. **Язык.** Основной язык сайта — украинский; новые двуязычные разделы
   поддерживают uk/ru через общий словарь переводов. Существующие страницы
   не переводить автоматически и не выдавать украинскую страницу за русскую.
   Комментарии в коде и описания коммитов — на русском или английском.
2. **Достоверность.** Не выдумывать цены, отзывы, реквизиты, график работы,
   номера телефонов и ссылки на социальные сети. Если данных нет, использовать
   явный плейсхолдер `TODO_OWNER` и перечислить все такие места в итоговом отчёте.
   Не выдавать плейсхолдер за реальные данные и не публиковать его на сайте:
   незаполненный материал остаётся черновиком до подтверждения владельцем.
3. **Сохранение URL.** Не удалять существующие URL. При изменении адреса
   добавить HTTP 301-редирект со старого URL на новый и проверить его работу.
4. **Скорость.** Не добавлять тяжёлые зависимости и фреймворки без необходимости.
   Сайт должен оставаться быстрым и статически отдаваемым там, где это возможно.
5. **Секреты.** Токены Telegram, ключи API и другие секреты никогда не должны
   попадать во фронтенд, репозиторий, коммиты или логи. Передавать их только через
   переменные окружения. Поддерживать `.env.example` без значений секретов;
   корневой шаблон содержит только имена переменных с пустыми значениями.
6. **Типографика.** В текстах использовать апостроф ’, украинские кавычки «»
   и тире —.
7. **Проверка и отчёт.** Перед завершением задачи запустить сборку или линтер,
   если они есть, проверить открытие затронутых страниц и отсутствие ошибок
   в консоли браузера. Дать краткий отчёт: что изменено, какие файлы затронуты,
   что проверено и какие `TODO_OWNER` остались. Если проверка недоступна,
   явно сообщить об этом; не выдавать непроведённую проверку за успешную.
8. **Коммиты.** Работать небольшими коммитами: один смысл на коммит.
