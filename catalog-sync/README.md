# ALT-CAM product catalog sync

Єдиний конвеєр: постачальники -> нормалізований каталог -> сайт -> Meta Commerce -> Google Drive.

## Джерела

- Viatec: сім тематичних українських XML-фідів: відеоспостереження,
  енергосистеми, домофонія, мережеве обладнання, сигналізація, монтажні
  матеріали, електрика та інструмент.
- Yugtorg: приватний API, ключ тільки через `YUGTORG_API_KEY`.

## Групи ALT-CAM

- камери;
- реєстратори та накопичувачі;
- домофони;
- Ajax/сигналізація;
- резервне живлення;
- контроль доступу;
- мережеве обладнання;
- електрика та інструмент;
- кронштейни, бокси та розподільчі коробки;
- кабель і з'єднання;
- монтажні матеріали та інструмент.

Закупівельні ціни не потрапляють у публічні фіди. Публікація товарів буде
увімкнена лише після затвердження правил націнки, наявності та брендингу.

## Локальний запуск

```powershell
python scripts/sync_product_catalog.py
```

Результат зберігається у `catalog-sync/output/`. Ця папка призначена для
тимчасової збірки та звітів, а не для ручного редагування товарів.

Публічна вітрина збирається у `catalog-data.js`, а повний фід Meta Commerce —
у `feeds/meta-catalog.csv`. Обидва файли будуються з одного нормалізованого
набору, тому назви категорій, ціни, описи й зображення збігаються. Планова
синхронізація GitHub Actions виконується кожні 4 години та оновлює обидва
файли без увімкненого ПК.

Редагований контрольний клон створюється як Google Sheets. Колонка
`Публікувати` призначена для редакторського контролю; закупівельні дані та
секрети до таблиці й публічних фідів не потрапляють.

## GitHub Secrets

- `YUGTORG_API_KEY` — новий ключ після заміни розкритого ключа.
- `GOOGLE_DRIVE_SERVICE_ACCOUNT_JSON` — JSON сервісного акаунта Google.

Кореневу папку Google Drive потрібно надати email сервісного акаунта з правом
редагування. Ідентифікатори папок вже записані у `config.json`.
