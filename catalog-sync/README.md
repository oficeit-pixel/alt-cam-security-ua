# ALT-CAM product catalog sync

Перший етап: постачальники -> нормалізований каталог -> Google Drive.

## Джерела

- Viatec: актуальний український XML `product_info_a_uk.xml`.
- Yugtorg: приватний API, ключ тільки через `YUGTORG_API_KEY`.

## Групи ALT-CAM

- камери;
- реєстратори та накопичувачі;
- домофони;
- Ajax/сигналізація;
- резервне живлення;
- контроль доступу;
- аксесуари;
- кронштейни, бокси та розподільчі коробки;
- кабель і з'єднання;
- монтажні матеріали та інструмент.

Закупівельні ціни не потрапляють у публічні фіди. Публікація товарів буде
увімкнена лише після затвердження правил націнки, наявності та брендингу.

## Локальний запуск

```powershell
python scripts/sync_product_catalog.py
```

Результат зберігається у `catalog-sync/output/`. Ця папка призначена для
тимчасової збірки та звітів, а не для ручного редагування товарів.

Публічна вітрина збирається у `catalog-data.js`, а повний фід Meta Commerce —
у `feeds/meta-catalog.csv`. Планова синхронізація GitHub Actions виконується
кожні 4 години та оновлює обидва файли без увімкненого ПК.

## GitHub Secrets

- `YUGTORG_API_KEY` — новий ключ після заміни розкритого ключа.
- `GOOGLE_DRIVE_SERVICE_ACCOUNT_JSON` — JSON сервісного акаунта Google.

Кореневу папку Google Drive потрібно надати email сервісного акаунта з правом
редагування. Ідентифікатори папок вже записані у `config.json`.
